# Test MIDI files

## Songs of PianoBooster (`bc*.mid`, `bm*.mid`)

These songs are part of the music of PianoBooster ("Booster Music"), copied from
`BoosterMusicBooks.zip` of the PianoBooster sources and renamed:

| Prefix | Folder in the zip |
|---|---|
| `bc` | `BoosterMusicBooks4/Beginner Course` |
| `bm` | `BoosterMusicBooks4/Booster Music` |

They are released under the **Creative Commons Attribution license (CC-BY)** by the
PianoBooster project (Louis James Barman and contributors):

- https://github.com/pianobooster/PianoBooster
- https://github.com/pianobooster/BoosterMusic

They are not changed, apart from their file names.
